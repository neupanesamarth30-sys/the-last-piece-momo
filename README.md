# The Last Piece MOMO

Windows desktop build. This repository includes the downloadable desktop package as `desktop.zip`.

## Run it

1. Clone this repository with Git LFS installed so the full `desktop.zip` downloads.
2. Extract `desktop.zip`.
3. Open `desktop/THE LAST PIECE MOMO.exe`.

Keep the `.pck` file and the `libterrabrush` DLL beside the `.exe` after extracting.
